# 🎬 Rotten Tomatoes Sentiment Analysis using BERT

This project demonstrates sentiment analysis on IMDB movie reviews using a fine-tuned **BERT (Bidirectional Encoder Representations from Transformers)** model. The model is trained on the IMDB dataset from Hugging Face and deployed with an interactive Gradio UI.

---

## 🚀 Features

* Fine-tuned BERT model for binary sentiment classification (Positive / Negative)
* Uses IMDB dataset from Hugging Face
* Interactive UI built with Gradio
* Real-time sentiment prediction
* Visual result examples included

---

## 🧠 Tech Stack

* Python
* PyTorch / Transformers
* Hugging Face Transformers
* Gradio
* NumPy, Pandas

---

## ⚡ Hardware Requirements
GPU: NVIDIA T4 (recommended for faster inference/training)
CPU: Can run on CPU, but significantly slower
RAM: Minimum 8GB recommended
